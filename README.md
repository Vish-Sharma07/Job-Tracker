# 💼 Job Tracker

A web-based job application tracker built with React, Vite, and Tailwind CSS to help job seekers organize, manage, and monitor their job applications in one place.

The project provides a simple interface for keeping track of applications and their progress throughout the job search journey.

## 🌐 Live Demo

👉 [Try Job Tracker](https://Vish-Sharma07.github.io/Job-Tracker/)

## ✨ Features

- ➕ Add job applications
- 🏢 Store company and job details
- 📊 Track application progress
- 🔄 Update application status
- 🔍 View and manage job applications
- 🎨 Clean and responsive user interface
- ⚡ Fast and interactive frontend experience

## 🛠️ Tech Stack

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Vish-Sharma07/Job-Tracker.git
```

Navigate to the project directory:

```bash
cd Job-Tracker
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal.
